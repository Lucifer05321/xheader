## 🌟 Features & Capabilities

- **📁 File System** — Browse directories remotely, chunked streaming for large files, ZIP downloads.
- **💻 Terminal** — Full interactive remote terminal with live stdout/stderr streaming.
- **📊 System Telemetry** — Live CPU, RAM, Disk, and Network monitoring.
- **⚡ Process Monitor** — View and kill processes remotely.
- **🔒 Security** — Silent background operation, auto-reconnect, zero console pollution.
- **🌐 Cross-Platform** — Full support for Android, Linux, macOS, and Windows.
